# Folder label (folder-label)

[繁體中文](./README.md) · **English**

Shows the current conversation's folder above the prompt box, on the left, such as `❐ my-project`. **Uses no tokens**.

- Only the last part of the path, in grey.
- Handy when your sidebar is sorted into your own groups and no longer shows folders.
- **With usage-meter**: usage-meter draws the folder name at the left of its button row, and this mod steps aside so it doesn't appear twice.
- Just a symbol and the folder name, so there's nothing to translate.

## Install

Add the marketplace from the collection's root folder (the one with `.claude-plugin/marketplace.json`), then install. Full steps: [collection README](../../README.en.md#3-install).

```bash
claude plugin install folder-label@tcan-claude-mods
```

## Remove

```bash
claude plugin uninstall folder-label@tcan-claude-mods
```
