# usage-time：交接說明

Claude Code 的 mod，用一個小工具顯示**使用時間**。可以跟 `../usage-meter/`（額度）分開安裝：只裝一個、或兩個都裝都行。

## 本週總計移到「本週各資料夾」標題後面
- 使用者要求：拿掉「今天」下面的「本週」那一行，本週總時間改寫在「本週各資料夾」同一行的右邊。這一行永遠顯示，就算還沒有資料夾資料也會顯示。

## 0.7.0：本週各資料夾百分比圖
- 使用者要知道**本週**的使用時間分別花在哪個資料夾（例如「claude閒聊」）。使用者說同一時間只會處理一個資料夾，不用處理資料夾之間的時間衝突。
- 每段時段多記一個資料夾：`[開始, 結束, 資料夾]`，資料夾是 `$.session.cwd()` 的最後一層（`folderName`）。`mergeByFolder`：同一個資料夾的時段合併（兩個對話開同一個資料夾不重複算），不同資料夾分開放。總時間仍用 `mergeSpans` 不分資料夾合併。
- `Day` 多了 `folders: { 資料夾: 毫秒 }`（`toDays` 算出來）。**usage-meter 的 contract 也宣告了 `Day`，兩邊型別要一致**。
- 畫面：週格子下面是「本週各資料夾」，一條分色的長條，加上每個資料夾一行「■ 名稱　75% · 90m」。前三名依序用藍 `#1A67F8`、青藍 `#0DCAFE`、紅 `#FF5561`，其餘併成「其他」灰色。改版前沒有資料夾的時段顯示「未分類（記資料夾之前）」。

## 0.6.0：所有對話的時間剔除重疊時段；顏色門檻改 1h/2h
- `$.store` 改存**時段**：key `stay-v3`，格式是 `{ 'YYYY-MM-DD': { spans: [[開始, 結束], ...], work } }`。每次算進去的「上一則 → 這一則」記成一段，跟所有對話的時段**合併**（`mergeSpans`），所以兩個對話同時開著（例如都是 9:00–10:00）只算一次。跨過半夜的時段切成兩天（`splitByDay`）。`days` atom 是由時段算出來的總和（`toDays`），usage-meter 照舊讀它。
- Claude 工作（`work`）每個對話各自加，不合併。
- 改版後從 0 開始：舊的 `days`、`days-v2` 只有分鐘數，沒辦法換算。
- 顏色門檻（使用者指定）：0 灰、**1 小時內淺藍 `#0DCAFE`、1–2 小時深藍 `#1A67F8`、2 小時以上紅 `#FF5561`**。
- 使用者要求拿掉：顏色說明那一行（「灰 0 · …」），以及「這次對話 · Claude 工作」那一行。按鈕上的「◷ 83m」仍是這次對話的時間。
- 測試新增：重疊只算一次（另一個對話的 09:10–09:30 被併進 09:00–09:40）、跨半夜切兩天。

## 0.5.0：時間改成「第一則訊息到最後一則訊息」
- 使用者要的是**停留在介面的時間，不算中間離開的時間**。Claude Code 沒有「正在看畫面」的訊號，所以定義成：**從第一則訊息到最後一則訊息**，兩則之間隔超過 30 分鐘（`GAP_MS`）就當作離開，那段不算。
- 實作：`prompt.submit`（排除 `isMeta` 和外掛送的）時，把「上一則 → 這一則」的間隔加進 `sessionMs`（這次對話）和今天的 `active`。`lastSubmitAt` 存在 `$.state`，重新載入不會遺失。
- Claude 跑的時間只算進「Claude 工作」（`work`），**不再**算進 `active`。
- 「這次對話」和按鈕「◷ 83m」都改成 `sessionMs`，不是「現在 − 對話開始」。
- 新算法的紀錄存在 `$.store` 的 `days-v2`。舊的 `days` 不再讀取，所以改版當天的「今天」從 0 開始。
- 測試案例：09:00、09:20、09:40、（去吃飯）13:00、13:10 → 50m。

## 0.10.1 / 0.4.1：TCAN logo 三色
- 使用者說的「TCAN 配色」是 **logo 的三個色塊**（tcan2050.org.tw），從 logo 吸色得到：青藍 `#0DCAFE`、藍 `#1A67F8`、紅 `#FF5561`。最早給的 `#1D5BD0 / #C22F3C / #1B87B0` 已全部換掉；本檔較早段落的色碼也已改成新的三色。
- 「用量與時間」小工具裡，額度和使用時間之間多空一行（`marginTop={2}`）。

## 需求（使用者的說法）
> 我還要想做一個使用時間的模組，他跟用量可以分別安裝，可以只有其中一個或是有兩個。不過同樣顯示在相同的位置

使用者選了要顯示以下四項，並要求兩個都裝時，兩顆按鈕**並排在同一行**：
- 這次對話開了多久
- Claude 實際工作的時間
- 今天總共用了多久
- 這週總共用了多久

## 畫面
- 輸入框右上方的按鈕「◷ 1h23m」（這次對話開了多久），點一下開關小工具。也可以輸入 `/usage-time`。
- 小工具（widget）內容：
  ```
  這次對話      1 小時 23 分   ← TCAN 青藍、粗體
  Claude 工作   18 分
  今天          2 小時 5 分
  本週          9 小時 40 分

  本週每天
  一 ██████████░░░  1h20m      ← TCAN 藍；今天用青藍；底色中性灰
  二 ...
  沒動超過 5 分鐘不算使用時間
  ```
- 風格跟 usage-meter 一致：TCAN 配色（藍 `#1A67F8`、青藍 `#0DCAFE`），**沒有外框**，底色中性灰（`subtle`）。顏色集中在 `PALETTE`。

## 怎麼算
- **這次對話**：現在減 `$.session.usage().startedAt`。
- **Claude 工作**：主對話每一輪 `turn.complete` 的 `durationMs` 加總，有 `agentId` 的子代理不算。存在 `$.state`。
- **今天／本週（使用時間）**：Claude 工作時間，加上「Claude 回完話 → 你送出下一則訊息」之間的時間（你在看、在打字），這段最多算 5 分鐘（`IDLE_MS`）。
  - 依日期存在 `$.store` 的 `days`（`{ 'YYYY-MM-DD': { active, work } }`），所有對話共用，保留 21 天。
  - 週一開始算一週。
- 每分鐘用 `$.clock.sleep` 迴圈更新 `tick`，讓畫面往前走。

## 已知限制
- 同時開好幾個對話時，「今天／本週」會重複算（各對話各自累加），`$.store` 寫入也可能互相覆蓋。
- 裝上之前的時間不會補算。
- 每一則訊息之前的第一段打字時間沒有算（只算回覆之後到下一則訊息之間）。

## 0.4.0：新版面（usage-meter 的下半部也一樣）
使用者的要求：
1. 最上面是「今天（所有對話）」，用粗體大字。下面是本週總計，再下面一行小字寫「這次對話 · Claude 工作」。
2. 本週每天用 TCAN 配色的顏色格：0 是灰（`subtle`），2 小時以內是淺藍 `#0DCAFE`，2–4 小時是深藍 `#1A67F8`，4 小時以上是紅 `#FF5561`（`dayColor`）。
3. 星期一到日**由左到右**排。
4. 每一欄由上到下：星期、顏色格、分鐘數。
5. 時間**一律用分鐘**，寫成「83m」，按鈕也是（`short`）。不要再用「1 小時 23 分」或「1h23m」。
- 每分鐘迴圈會重新讀 `$.store` 的 `days`，所以別的對話累積的時間也會反映在「今天」。

## 0.3.0：usage-meter 直接讀這裡的狀態
- `/usage-time data` 拿掉了：外掛呼叫指令會在對話裡留下一串 JSON。usage-meter 改成直接讀 `$.state` 的 `workMs` 和 `days`，所以**這兩個 key 的名字和型別不要改**，要改的話 usage-meter 也要一起改。
- 兩個都裝時，時間那一段由 usage-meter 的「◷」按鈕開關；`/usage-time` 只回提示。
- 單獨裝時，按鈕打開後變「◷ 收起」（新增 `isOpen` 狀態，× 關掉時歸零）。

## 0.2.0：跟 usage-meter 共用同一個小工具（資料傳法已被 0.3.0 取代）
- 使用者要額度和使用時間在**同一個畫面上下兩段**。兩個都裝時，由 usage-meter 的小工具一起畫（上額度、下時間），usage-time 自己的小工具不用。
- usage-time 回應 `/usage-time data`，回傳 JSON（`TimeData`，見 `types/index.d.ts`），給 usage-meter 讀。
- 兩個都裝時，`/usage-time` 只回提示「請按按鈕或 /usage-meter」，因為指令裡不能再呼叫別的指令。
- 只裝 usage-time 時，一切照舊（自己的按鈕、自己的小工具）。

## 跟 usage-meter 並排
輸入框上方每個 mod 只能畫自己那一行，不能左右並排。所以：
- **只裝 usage-time**：自己畫按鈕（`key="toggle"`）。
- **兩個都裝**：usage-time 用 `$.command.list()` 看到 `usage-meter` 指令，就不畫；由 usage-meter 在同一行畫「◷」按鈕，按下時呼叫 `/usage-time`。
- 改按鈕樣式時，兩邊的 `short` / `shortTime` 要保持一致。

## 檔案與開發
| 檔案 | 用途 |
| --- | --- |
| `.claude-plugin/plugin.json` | manifest |
| `hooks/register.tsx` | 主程式 |
| `hooks/register.test.tsx` | 3 個測試：單獨畫按鈕、讓給 usage-meter、只算主對話 |
| `types/index.d.ts` | `$.state` 合約 |

- 驗證：`claude plugin validate <資料夾>`；測試：`claude plugin test <資料夾>`。
- 這台 Mac 的 claude 不在 PATH 上，執行檔在 `~/Library/Application Support/Claude-Tcan/claude-code/<版本>/.../claude.app/Contents/MacOS/claude`。
